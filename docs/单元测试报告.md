# 单元测试报告 - VoxAudit 智能质检系统

## 测试范围

本报告涵盖后端核心模块的单元测试内容，覆盖 API 接口层、业务逻辑层和服务层。

---

## 1. 认证模块 (`backend/api/auth.py`)

| 用例编号 | 测试内容 | 预期结果 |
|----------|----------|----------|

| AUTH-006 | 用户登出接口调用 | 返回 200，Token 被加入黑名单 |

| AUTH-008 | 使用他人 Refresh Token 刷新 | 返回 401 错误，Token 不匹配 |
